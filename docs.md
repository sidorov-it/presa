# Варианты перетаскивания элементов

## Перетаскивание относительно одного элемента

1. + Перенос элемента над другим элементом сверху (добавление перед целевым элементом)
2. + Перенос элемента под другим элементом снизу (добавление после целевого элемента)
3. + Перенос элемента слева от другого элемента (добавление перед целевым элементом в строке)
4. + Перенос элемента справа от другого элемента (добавление после целевого элемента в строке)

## Перетаскивание внутри многоячеистых строк

5. Перенос элемента сверху к другому элементу внутри ячейки (создание новой строки перед целевой ячейкой)
6. Перенос элемента снизу к другому элементу внутри ячейки (создание новой строки после целевой ячейки)
7. Перенос элемента слева к другому элементу внутри ячейки (добавление в качестве новой ячейки слева от целевой)
8. Перенос элемента справа к другому элементу внутри ячейки (добавление в качестве новой ячейки справа от целевой)

## Перетаскивание 1 элемента (единственного в строке)

9. Перенос 1 элемента перед другим 1 элементом (перемещение всей строки выше целевой строки)
10. Перенос 1 элемента после другого 1 элемента (перемещение всей строки ниже целевой строки)
11. Перенос 1 элемента слева/справа от другого 1 элемента (объединение строк в многоячеистую строку)

## Перетаскивание многоячеистых строк

12. Перенос всей многоячеистой строки перед другой строкой
13. Перенос всей многоячеистой строки после другой строки
14. Перенос всей многоячеистой строки для объединения с другой многоячеистой строкой

## Перетаскивание между ячейками внутри строки

15. Перенос элемента из одной ячейки в другую ячейку в той же строке (замена элемента)
16. Перенос элемента из одной ячейки для объединения с элементом в другой ячейке (группировка)

## Перетаскивание между уровнями вложенности

17. Перенос элемента из вложенной структуры на верхний уровень
18. Перенос элемента с верхнего уровня во вложенную структуру
19. Перенос элемента между разными уровнями вложенности

## Перетаскивание с изменением размеров ячеек

20. Перенос элемента с увеличением целевой ячейки (расширение)
21. Перенос элемента с уменьшением исходной ячейки (сужение)
22. Перенос элемента с перераспределением размеров всех ячеек в строке

## Перетаскивание пустых мест

23. Перенос элемента в пустую ячейку
24. Перенос элемента для создания новой пустой ячейки

## Специальные случаи

25. Перенос элемента с копированием (дублирование элемента)
26. Перенос элемента с объединением содержимого (слияние элементов)
27. Перенос с заменой существующего элемента (замещение)
28. Перенос с обменом позициями (своп элементов)

Это довольно исчерпывающий список основных вариантов перетаскивания элементов, который охватывает различные сценарии и возможные результаты перемещения элементов в интерфейсе.
