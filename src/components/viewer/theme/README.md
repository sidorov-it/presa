# Документация по компонентам темы

## Обзор

Этот каталог содержит компоненты для применения тем презентаций. Существует два основных компонента, которые по-разному обрабатывают применение тем.

## Компоненты

### ThemeStylesApplier

**Назначение**: применяет стили темы к локальному элементу контейнера для просмотра презентации на всю страницу.

**Использование**:
- Используется на странице `/view/[id]` для просмотра презентации
- Используется на странице `/docs/[id]` для редактирования презентации  
- Используется на странице `/test/[id]` для тестирования

**Как это работает**:
- Применяет CSS-переменные к своему собственному элементу-контейнеру (не document.documentElement)
- Включает функцию очистки, которая удаляет стили при отключении компонента
- Автоматически использует DEFAULT_THEME, когда тема равна null
- Устанавливает цветовой режим (темный/светлый) в зависимости от темы

**Применяемые CSS-переменные**: 
Все переменные с префиксом `--presentation-*`, такие как:
- `--presentation-primary-accent`
- `--presentation-slide-background`
- `--presentation-heading-color`
- и т. д.

### ScopedThemeStylesApplier

**Назначение**: Применяет стили темы к контейнеру с ограниченной областью действия для компонентов предварительного просмотра.

**Использование**:
- Используется в компоненте `SlidePreview` на панели инструментов.
- Используется в `ScopedPresentationThemeWrapper`. 

**Как это работает**:
- Применяет CSS-переменные только к собственному элементу контейнера.
- Не влияет на глобальные стили.
- Теперь автоматически использует DEFAULT_THEME, когда тема равна null (исправлено).
- Облегченная версия без управления цветовым режимом.

**Ключевые различия**:

| Функция | ThemeStylesApplier | ScopedThemeStylesApplier |
|---------|-------------------|-------------------------|
| Область действия | Область действия контейнера | Область действия контейнера |
| Цветовой режим | Устанавливается глобально | Без управления цветовым режимом |
| Тема по умолчанию | Да | Да (теперь исправлено) |
| Очистка | Да | Да |
| Пример использования | Полные страницы презентации | Компоненты предварительного просмотра |

## Последние исправления

1. **ScopedThemeStylesApplier**: теперь применяет DEFAULT_THEME, когда тема равна null.
2. **SlidePreview**: исправлены проблемы с шириной путем удаления масштабирования.
3. **themeUtils**: добавлена функция `clearAllThemeStyles()` для полной очистки.

## Очистка переменных CSS

Используйте `clearAllThemeStyles()` из `@/utils/themeUtils`, чтобы полностью удалить все CSS-переменные, связанные с темой, из `document.documentElement`. Это полезно при переходе с тематических страниц.

```typescript
import { clearAllThemeStyles } from „@/utils/themeUtils“;

// Очистить все переменные темы
clearAllThemeStyles();
```
