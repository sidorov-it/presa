# Тестирование генерации слайдов

Эта страница позволяет тестировать 6-й этап процесса генерации слайдов - заполнение шаблона контентом.

## Как использовать

1. **Получите JSON из логов**: Найдите в логах запись с `functionArguments`, которая содержит параметры, с которыми LLM вызывает функцию генерации контента.

2. **Вставьте JSON**: Скопируйте содержимое `functionArguments` и вставьте в текстовое поле.

3. **Выберите шаблон**: Выберите шаблон слайда из выпадающего списка.

4. **Создайте слайд**: Нажмите кнопку "Создать слайд" для генерации предварительного просмотра.

## Пример JSON

```json
{
  "title": "Заголовок слайда",
  "content": "Основной контент слайда",
  "subtitle": "Подзаголовок"
}
```

## Структура functionArguments

JSON должен содержать ключи, соответствующие слотам в выбранном шаблоне. Каждый слот имеет:
- `originalSlot` - оригинальное имя слота в шаблоне
- `elementTypeId` - тип элемента (текст, изображение, список и т.д.)
- `textType` - тип текста (заголовок, обычный текст и т.д.)

## Отладка

Если слайд не создается корректно:
1. Проверьте, что JSON валиден
2. Убедитесь, что ключи в JSON соответствуют слотам шаблона
3. Проверьте консоль браузера на наличие ошибок

## Технические детали

Страница использует:
- `createSlideFromTemplateWithContent` для создания слайда
- `SlideViewer` для отображения результата
- `SlideTemplatesRegistry` для получения доступных шаблонов
