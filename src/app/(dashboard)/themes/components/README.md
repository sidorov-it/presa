# ThemePreview Component

Компонент предпросмотра темы для отображения карточки с превью темы презентации.

## Описание

`ThemePreview` - это React компонент, который отображает карточку с предпросмотром темы. Карточка содержит:

- **Превью области**: Прямоугольный блок с фоном темы и образцом слайда
- **Образец слайда**: Мини-карточка с заголовком, текстом и ссылкой в стилях темы
- **Информационная панель**: Название темы и кнопка меню (три точки)

## Пропсы

```typescript
interface ThemePreviewProps {
    theme: Theme;           // Объект темы с настройками цветов, типографики и дизайна
    onMenuClick?: (theme: Theme) => void;  // Колбэк для обработки клика по меню
}
```

## Использование

```tsx
import ThemePreview from './ThemePreview';
import { Theme } from '@/types/theme';

const MyComponent = () => {
    const handleMenuClick = (theme: Theme) => {
        console.log('Открыть меню для темы:', theme.name);
        // Логика открытия меню
    };

    return (
        <ThemePreview 
            theme={myTheme} 
            onMenuClick={handleMenuClick} 
        />
    );
};
```

## Особенности

### Адаптивность
- Компонент адаптируется под разные размеры экрана
- На мобильных устройствах уменьшается размер превью и текста

### Доступность
- Кнопка меню поддерживает навигацию с клавиатуры
- Есть aria-label для скрин-ридеров
- Поддерживается фокус с клавиатуры

### Интерактивность
- Hover эффект с поднятием карточки
- Анимированные переходы
- Кликабельная кнопка меню

## Стили

Компонент использует CSS модули (`ThemePreview.module.css`) для стилизации:

- `.themeCard` - основная карточка
- `.previewContainer` - контейнер превью
- `.slideCard` - образец слайда
- `.themeInfo` - информационная панель
- `.menuButton` - кнопка меню

## Зависимости

- `@/types/theme` - типы для темы
- `@/components/ui/Card/Card` - базовый компонент карточки
- CSS модули для стилизации

## Примеры тем

Компонент корректно отображает различные типы тем:
- Темы с цветным фоном
- Темы с изображением в качестве фона
- Различные настройки типографики
- Разные стили границ и теней
