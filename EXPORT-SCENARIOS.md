# 📤 Экспорт в MockGPT сценарии

Быстрое руководство по экспорту LLM запросов в формат тестовых сценариев MockGPT.

## 🎯 Зачем это нужно

- **Воспроизведение багов:** Сохраните проблемные ответы для тестирования исправлений
- **Регрессионные тесты:** Убедитесь, что изменения не сломали работающие случаи
- **Быстрое создание тестов:** Автоматически генерируйте сценарии из реальных данных

## 🚀 Как использовать

### 1. Найдите проблемный запрос

1. Перейдите на `/tech-llm-analytics`
2. Найдите запрос с проблемой (например, по фильтру пользователя)
3. Кликните на Request ID для перехода к деталям

### 2. Экспортируйте сценарий

1. На странице деталей нажмите **"📤 Export as MockGPT Scenario"**
2. Заполните форму:
   - **Название:** Описательное имя (например, "Formatting Issues Test")
   - **Описание:** Что тестирует сценарий
3. Выберите способ сохранения:
   - **Download JSON** - скачать файл
   - **Save to Project** - сохранить в `src/services/llm/mockGpt/scenarios/`

### 3. Используйте сценарий

```bash
# Если скачали файл - поместите в папку scenarios/
cp downloaded-scenario.json src/services/llm/mockGpt/scenarios/

# Активируйте сценарий
node scripts/test-scenarios.js set your-scenario-name

# Теперь создавайте презентации - будут использованы экспортированные ответы
```

## 📋 Что экспортируется

### ✅ Включается в экспорт
- Успешные запросы с ответами
- Function calls и их аргументы  
- Умные триггеры (автоматическое определение)
- Метаданные запросов

### ❌ Исключается из экспорта
- Неуспешные запросы
- Запросы без ответов
- Чувствительные данные пользователей

## 🔧 Умные триггеры

Система автоматически определяет лучший тип триггера:

| Тип | Когда используется | Пример |
|-----|-------------------|---------|
| `function_name` | Есть вызов функции | `generate_slide_text` |
| `template_id` | Упоминается шаблон | `two-columns`, `welcome-slide` |
| `prompt_contains` | Остальные случаи | Первые 50 символов промпта |

## 📝 Пример экспортированного файла

```json
{
  "name": "Formatting Issues Test",
  "description": "Reproduces text formatting problems in slides",
  "responses": [
    {
      "id": "exported-response-1",
      "description": "Exported from yagpt - generate_content",
      "trigger": {
        "type": "function_name",
        "value": "generate_slide_text"
      },
      "response": {
        "elements": [],
        "function_call": {
          "name": "generate_slide_text",
          "arguments": {
            "title": "**Заголовок без закрытия",
            "content": "Проблемный контент..."
          }
        }
      }
    }
  ]
}
```

## 🔄 Workflow для отладки

1. **Пользователь сообщает о проблеме** с форматированием
2. **Найдите его запрос** в аналитике по User ID
3. **Экспортируйте проблемный сценарий**
4. **Активируйте MockGPT** с этим сценарием
5. **Воспроизведите проблему** локально
6. **Исправьте код** форматирования
7. **Протестируйте исправление** с тем же сценарием

## 💡 Советы

### Для разработчиков
- Экспортируйте сценарии перед крупными изменениями
- Создавайте сценарии для каждого типа шаблона
- Используйте описательные названия

### Для тестирования
- Комбинируйте несколько проблемных запросов в один сценарий
- Регулярно обновляйте тестовые сценарии
- Документируйте ожидаемое поведение

### Для отладки
- Сохраняйте и исходный, и исправленный сценарии
- Используйте Raw данные для глубокого анализа
- Проверяйте все связанные запросы в группе
