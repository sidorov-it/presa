# Presa - Создание презентаций с помощью ИИ

Presa - это веб-инструмент для создания слайдов, аналогичный gamma.app. Этот инструмент позволяет пользователям генерировать слайды с помощью ИИ, редактировать их вручную и экспортировать в различные форматы.

## Основные возможности

### Добавление элементов на слайд:

- **Текст** (заголовки, параграфы, списки)
- **Изображения** (загруженные пользователем или сгенерированные ИИ)
- **Разделители** (линии, пробелы, декоративные элементы)
- **Иконки** (выбор из библиотеки иконок)
- **Видео** (загрузка или вставка по ссылке, например, YouTube)
- **Графики и диаграммы** (автоматическая генерация по данным)
- **Кнопки** (с возможностью настройки действий, таких как переход по ссылке)

Элементы поддерживают перемещение, изменение размеров, редактирование содержимого и стилизацию (цвет, шрифт, фон и т.д.).

### Макеты (Layouts):

- **Одна колонка** (стандартный блок текста или изображения)
- **Две колонки** (автоматически адаптируются при добавлении третьей)
- **Три колонки** (расширяемый макет, поддержка добавления/удаления колонок)
- **Четыре иконки с описанием** (можно добавлять дополнительные иконки, слайд перестраивается автоматически)
- **Изображение + текст** (адаптируется в зависимости от размера изображения)
- **Карточки** (сетка элементов с динамической шириной/высотой)

При добавлении нового элемента или изменении количества колонок макет автоматически перестраивается, сохраняя пропорции и выравнивание.

### Редактор слайдов:

- Drag-and-drop для перемещения элементов
- Изменение размеров и расположения элементов в реальном времени
- Выравнивание элементов по сетке
- Автоадаптация контента под размер слайда
- Поддержка кастомных стилей для макетов
- Встроенный просмотр презентации в браузере
- Поддержка общего доступа через ссылку

### Генерация контента с помощью ИИ:

- Генерация текстового контента на основе запроса пользователя
- Генерация изображений на основе запроса пользователя

### Экспорт презентаций:

- PDF
- PPTX (Microsoft PowerPoint)
- PNG (изображения слайдов)
- HTML (веб-презентация)

## Миграции MongoDB (Prisma)

- Миграции лежат в папке `prisma/migrations/`.
- Для запуска всех миграций используйте:
  ```sh
  npm run migrate
  # или
  yarn migrate
  ```
- Новая миграция — это файл вида `NNN-description.ts` с экспортом функции `up(db: Db)`.
- Пример:
  ```ts
  import { Db } from "mongodb";
  export async function up(db: Db) {
    await db.collection("User").updateMany({}, { $set: { demoField: true } });
  }
  ```
- Применённые миграции отмечаются в коллекции `_migrations` в MongoDB.
