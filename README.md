# Slydle 🎯

**Умные презентации с искусственным интеллектом**

Slydle — это веб-платформа для создания профессиональных презентаций с помощью ИИ. Российский аналог gamma.app, адаптированный для русскоязычной аудитории.

## 🚀 О проекте

### 10X Миссия
Революционизируем способ человеческой коммуникации через презентации. Делаем каждого человека мастером влияния.

### 10X Видение  
Стать абсолютным лидером ИИ-презентаций в России и СНГ. IPO на Мосбирже с оценкой 200-400 млрд₽ к 2025 году.

### Ключевые преимущества
- **ИИ-генерация**: Создание полных презентаций из краткого описания
- **Визуальный редактор**: Drag-and-drop интерфейс для точной настройки
- **Темы и стили**: Профессиональные дизайн-шаблоны
- **Экспорт**: PDF, PPTX, HTML-форматы
- **Русский язык**: Полная локализация и оптимизация для русскоязычных пользователей
