# Тестирование сценария оплаты

## Что реализовано

✅ **Полная интеграция с YooKassa**
- Создание платежей через API
- Обработка webhook уведомлений
- Автоматическое зачисление токенов
- Отслеживание статуса в реальном времени

✅ **Обновленная страница /dashboard/tokens**
- Интеграция с YooKassa вместо тестовых платежей
- Красивые карточки пакетов токенов
- Уведомления о статусе платежа
- Автоматическое обновление баланса

## Сценарий тестирования

### 1. Подготовка

1. Убедитесь, что приложение запущено: `npm run dev`
2. Откройте браузер и перейдите на `http://localhost:3000`
3. Войдите в систему (если требуется аутентификация)

### 2. Переход на страницу токенов

1. Перейдите на `/dashboard/tokens`
2. Вы должны увидеть:
   - Текущий баланс токенов
   - 4 пакета токенов (Пробный, Базовый, Популярный, Профессиональный)
   - Кнопки "Оплатить через YooKassa" для каждого пакета

### 3. Тестирование создания платежа

1. Нажмите на кнопку "Оплатить через YooKassa" для любого пакета
2. Должно произойти:
   - Создание заказа в БД
   - Перенаправление на страницу оплаты YooKassa
   - Или ошибка, если не настроены переменные окружения

### 4. Проверка API endpoints

```bash
# Получение пакетов токенов
curl http://localhost:3000/api/tokens/packages

# Создание платежа (требует аутентификации)
curl -X POST http://localhost:3000/api/tokens/purchase/yookassa \
  -H "Content-Type: application/json" \
  -d '{"packageId": "PACKAGE_ID"}'
```

## Настройка для полного тестирования

### 1. Переменные окружения

Добавьте в `.env.local`:

```env
# YooKassa (получите в личном кабинете)
YOOKASSA_SHOP_ID=your_shop_id_here
YOOKASSA_SECRET_KEY=your_secret_key_here

# URL для webhook
NEXTAUTH_URL=http://localhost:3000
```

### 2. Настройка webhook (для продакшн)

1. Используйте ngrok для локального тестирования:
   ```bash
   ngrok http 3000
   ```

2. В личном кабинете YooKassa добавьте webhook:
   - URL: `https://your-ngrok-url.ngrok.io/api/webhooks/yookassa`
   - События: `payment.succeeded`, `payment.canceled`, `payment.waiting_for_capture`

### 3. Тестовые карты YooKassa

**Успешная оплата:**
- Номер: `5555 5555 5555 4444`
- Срок: любая будущая дата
- CVC: любые 3 цифры

**Отклоненная оплата:**
- Номер: `5555 5555 5555 5557`
- Срок: любая будущая дата
- CVC: любые 3 цифры

## Ожидаемое поведение

### При успешной оплате:
1. Пользователь перенаправляется на YooKassa
2. Вводит данные тестовой карты
3. YooKassa отправляет webhook на наш сервер
4. Система автоматически зачисляет токены
5. Пользователь видит обновленный баланс

### При отмене оплаты:
1. Статус покупки обновляется на "canceled"
2. Токены не зачисляются
3. Пользователь может попробовать снова

## Логирование

Все операции логируются в консоль:
- Создание платежей
- Обработка webhook
- Зачисление токенов
- Ошибки

Проверяйте логи в терминале где запущен `npm run dev`.

## Troubleshooting

### Ошибка "YOOKASSA_SHOP_ID is not defined"
- Добавьте переменные окружения в `.env.local`
- Перезапустите сервер

### Webhook не приходят
- Убедитесь, что URL доступен из интернета (используйте ngrok)
- Проверьте настройки webhook в YooKassa

### Токены не зачисляются
- Проверьте логи webhook в консоли
- Убедитесь, что статус платежа "succeeded"
