## Сценарий оплаты

1. **Пользователь заходит на `/dashboard/tokens`**
2. **Выбирает пакет токенов и нажимает "Оплатить через YooKassa"**
3. **Создается заказ в БД со статусом `pending`**
4. **Пользователь перенаправляется на страницу оплаты YooKassa**
5. **После оплаты YooKassa отправляет webhook**
6. **Система автоматически зачисляет токены**
7. **Пользователь видит обновленный баланс**
