# Настройка YooKassa для Slydle

## Обзор

Интеграция с YooKassa позволяет пользователям покупать токены для использования AI-функций в приложении Slydle. Система поддерживает:

- Создание платежей через YooKassa API
- Обработка webhook уведомлений
- Автоматическое зачисление токенов после успешной оплаты
- Отслеживание статуса платежей в реальном времени

## Настройка YooKassa

### 1. Создание магазина в YooKassa

1. Зарегистрируйтесь на [yookassa.ru](https://yookassa.ru)
2. Создайте магазин в личном кабинете
3. Получите `shopId` и `secretKey` в разделе "Настройки" → "API"

### 2. Переменные окружения

Добавьте в файл `.env.local`:

```env
# YooKassa
YOOKASSA_SHOP_ID=your_shop_id_here
YOOKASSA_SECRET_KEY=your_secret_key_here

# Для webhook (должен быть доступен из интернета)
NEXTAUTH_URL=https://yourdomain.com
```

### 3. Настройка Webhook

В личном кабинете YooKassa:

1. Перейдите в "Настройки" → "Уведомления"
2. Добавьте URL: `https://yourdomain.com/api/webhooks/yookassa`
3. Выберите события:
   - `payment.succeeded`
   - `payment.canceled`
   - `payment.waiting_for_capture`

## Архитектура системы

### API Endpoints

- `POST /api/tokens/purchase/yookassa` - создание платежа
- `POST /api/webhooks/yookassa` - обработка уведомлений
- `GET /api/tokens/purchase/status/[purchaseId]` - проверка статуса

### Компоненты

- `YooKassaPaymentButton` - кнопка оплаты
- `PaymentStatus` - отслеживание статуса
- `TokenPurchaseModal` - модальное окно покупки
- `useYooKassaPayment` - хук для работы с платежами

### Процесс оплаты

1. Пользователь выбирает пакет токенов
2. Создается запись в БД со статусом `pending`
3. Создается платеж в YooKassa
4. Пользователь перенаправляется на страницу оплаты
5. После оплаты YooKassa отправляет webhook
6. Система обрабатывает webhook и зачисляет токены

## Тестирование

### Тестовые карты YooKassa

Для тестирования используйте:

**Успешная оплата:**
- Номер: `5555 5555 5555 4444`
- Срок: любая будущая дата
- CVC: любые 3 цифры

**Отклоненная оплата:**
- Номер: `5555 5555 5555 5557`
- Срок: любая будущая дата
- CVC: любые 3 цифры

### Локальное тестирование

Для тестирования webhook локально используйте ngrok:

```bash
# Установите ngrok
npm install -g ngrok

# Запустите туннель
ngrok http 3000

# Используйте полученный URL для webhook
# Например: https://abc123.ngrok.io/api/webhooks/yookassa
```

## Безопасность

- Все платежи проходят через защищенные каналы YooKassa
- Webhook подписи валидируются для предотвращения подделки
- Секретные ключи хранятся в переменных окружения
- Повторное зачисление токенов предотвращается проверкой статуса

## Мониторинг

Система логирует:
- Создание платежей
- Обработку webhook
- Ошибки платежей
- Зачисление токенов

Логи можно найти в консоли сервера и в базе данных (таблица `TokenTransaction`).

## Troubleshooting

### Проблема: Webhook не приходят

1. Проверьте URL webhook в настройках YooKassa
2. Убедитесь, что сервер доступен из интернета
3. Проверьте логи сервера на ошибки

### Проблема: Токены не зачисляются

1. Проверьте статус платежа в YooKassa
2. Проверьте логи webhook в консоли
3. Убедитесь, что `purchaseId` корректно передается

### Проблема: Ошибки создания платежа

1. Проверьте правильность `YOOKASSA_SHOP_ID` и `YOOKASSA_SECRET_KEY`
2. Убедитесь, что магазин активен в YooKassa
3. Проверьте формат данных платежа

## Дополнительные возможности

### Возвраты

Для обработки возвратов можно добавить:

```typescript
// В webhook handler
case 'refund.succeeded':
    await handleRefund(refund);
    break;
```

### Подписки

Для регулярных платежей можно использовать:
- Сохраненные карты
- Автоплатежи YooKassa

### Аналитика

Данные о платежах доступны в:
- Таблице `TokenPurchase`
- Таблице `TokenTransaction`
- Личном кабинете YooKassa
